# 更新日志

适用于 Minecraft 26.3 Fabric。

## [未发布]

### 变更

- 保留生命周期诊断，将详细性能计时改为按需开启，降低正常游玩时的统计开销。
- 减少动态几何重复解码、变换与上传区间分配；不改变分辨率、采样数、反弹次数或场景范围。
- 用硬件可见性分组分离世界与第一人称模型，减少重复遍历；Foundation 的阴影查询跳过完整命中着色，不透明世界表面跳过透明覆盖检查，保持画质参数不变。
- 光影包帧与场景接口更新为 ABI 4，需要与对应的 Foundation 包一起更新。

### 修复

- 修正 GPU 性能查询的提交归属与未写入查询读取，补全加速结构和光追阶段的采样。
- 动态几何复用改为精确字节比较，消除哈希碰撞导致场景错误复用的风险；补充按需开启的 OpenGL 交接计时。
- 恢复第一人称相机对玩家身体的隐藏，以及手和手持物仅在视图模型射线中的可见性。
- 恢复玩家皮肤透明、半透明区域和阴影射线的覆盖判定。
