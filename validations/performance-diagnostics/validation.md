# 诊断开销与渲染阶段采样

## 目标

在相同隔离世界、分辨率与光影参数下，对比关闭、CPU、CPU 与 GPU 诊断。确认 GPU 查询能返回已完成的阶段耗时，统计工具不会把有限的帧历史当作整个采样窗口。

## 运行

需要 Python 与 Windows PowerShell 7。驱动首次运行时从空区段验证自己的隔离世界复制 fixture；不读取日常实例或 Prism。先构建发行模组与 Foundation 包，再从仓库根目录运行：

```powershell
.\gradlew.bat :automation:profileDiagnostics
```

实例位于本验证的 `instance/26.3-fabric/client/`，结果位于 `result/diagnostics/`，每次运行覆盖该目录。锁文件与临时文件写入本验证的 `instance/`。向 Gradle 传入 `-PleaveRunning=true`，或直接运行驱动时使用 `-LeaveRunning`，可留下可见的测试客户端，便于人工观察。采样期间关闭垂直同步、后台暂停与 AFK 限帧，光影质量参数保持不变。采样后关闭详细诊断。

对比本验证实例里已经存在的其他世界时，可直接向驱动传入 `-WorldName '存档文件夹名'`。驱动只改变本次 quick-play 参数，不改动模板文件或验证预设；不复制缺失的其他世界，也不执行 fixture 的方块变更。这种运行可以没有地形 BLAS 样本，报告为未测量；完整地形生命周期覆盖仍由默认 fixture 运行证明。

## 通过标准

各窗口都有 PT 帧计数；没有暂停或低于正常上限的后台限帧；关闭模式没有详细 CPU/GPU 样本；完整模式有光追、TLAS 与地形 BLAS 的 GPU 样本，查询失败数为零。动态 BLAS 可以因几何复用而没有样本，此时记录为未测量。方块更新后场景继续执行，客户端不崩溃。

完整模式还要得到 `GlScene` 和 `GlHandoff` 的样本，关闭模式不得有 OpenGL 时间戳样本。后者包含 Vulkan 执行，不能作为纯互操作开销。查询租约不可在未完成时复用，窗口重置不得混入旧样本。

吞吐量来自采样窗口的帧计数差，表示 PT 回调速率，不等于实际显示帧率。帧间隔最多保留最后 512 条；CPU 范围存在嵌套，GPU 时间包含对应命令段的依赖等待，不能把这些数值直接相加当作总帧耗时。开销对照报告实测差异，不使用固定性能提升作为通过标准。
